# 考研英语单词大观 · 智能主动回忆与复习系统

> 结合《考研英语一/二·纯净版单词大观》PDF（带真题例句与构词）与 LazyNote 考研高频 1199 榜单的全量真题背词系统。遵循主动回忆与自适应 SM-2 间隔重复曲线，支持暖米纸感与暗黑护眼双主题，以及学习轨迹足迹坞（Visit-Dock）。

---

## 🌟 核心功能与设计哲学

### 1. 严格的主动回忆学习闭环
$$\text{看英文原词与音标} \longrightarrow \text{自主回忆中文义与考点} \longrightarrow \text{揭晓真题释义与例句} \longrightarrow \text{三档自评与即时纠偏} \longrightarrow \text{自适应调度复习}$$
- **正面纯净无提示**：卡片正面仅保留英文单词、国际音标、真题考频与高频榜位，绝不提前泄露任何中文释义或中文词性。
- **背面全息答案解析**：揭晓后展示全量考研已考词义、词性、词根构词分析、1998–2026 年历年考研真题英文原句、权威中文译文以及出处题号。

### 2. 「记错了」核心撤销与防虚假掌握
- **误判即时挽回**：自评为「认识」后，卡片保留低调的「记错了？立即纠错 [Z]」入口。
- **回退机制**：点击后立即撤销本次认识带来的掌握度加成，记录一次错误事件，将单词加入错词强化队列，并在 15 分钟内安排短期复测。
- **跨卡片与足迹纠错**：支持翻到下一词后点击撤销横幅，或在右下角「足迹坞（Visit-Dock）」抽屉中随时对历史判断进行纠偏。

### 3. 全量无损真题词库 + 1199 考研高频考点
- **英语一词库**：630 页全量解析，3,398 词，5,113 条考研释义与例句。
- **英语二词库**：517 页全量解析，3,004 词，4,406 条考研释义与例句。
- **高频 1199 官方考点榜**：深度对齐并补全 LazyNote 考研 1199 官方高频词单（涵盖 `would`, `author`, `data`, `risk`, `tax` 等），标注 CEFR 等级（B1~C2）与高频位次（如 `🔥高频 #1`）。
- **双卷独立开关**：支持「英语一」、「英语二」及「双卷合并」一键切换，词库间互不干扰。

### 4. 纸质视觉规范与学习轨迹
- **暖米色纸质感（主色 `#faf8f5`）**：模拟纸质教辅书舒适阅读质感，大幅降低长时间背词的用眼疲劳。
- **暗黑护眼模式（Dark Mode `#141413`）**：柔和石墨黑夜读主题，支持顶部导航一键无缝切换与系统偏好自动同步。
- **学习足迹坞（Visit-Dock）**：右下角常驻足迹浮动坞，记录今日学习时序轨迹，支持随时回看、发音、查看详情或修正历史自评。

### 5. 分年份真题专项背诵（2010–2026）
- **逐年深度突破**：涵盖 2010 至 2026 年最新考研真题，每一年份均收录约 500 个真实考点核心词。
- **考点原句专属高亮**：卡片背面自动识别并高亮标注当年真题原句，带 `🎯 {年份}考点原句` 徽章，精准还原试卷原题上下文。
- **真题考频智能调度**：针对当年真题错词优先复测、未学词按考频降序突击、已学词智能循环温习。

## ⌨️ 全键盘快捷键

| 按键 | 功能说明 |
| :--- | :--- |
| `Space` / `Enter` | 翻转卡片揭晓释义 / 切换至下一个单词 |
| `1` | 自评：**不认识**（想不起，安排短时强化） |
| `2` | 自评：**不熟悉**（有印象但不准确，缩短复习间隔） |
| `3` | 自评：**认识**（回忆准确，拉长复习周期） |
| `Z` | **记错了？立即纠错**（撤销认识，扣减掌握度并启动紧急复测） |
| `S` | **美音原声朗读**（双引擎：Web Speech API + 有道真声音频流） |
| `F` | **星标收藏** / 取消收藏 |

## 🛠️ 技术栈架构

- **前端框架**：React 18 + TypeScript + Vite 5
- **原子样式**：Tailwind CSS (暖米纸质 `#faf8f5` + 石墨夜读 `#141413`)
- **持久化**：IndexedDB (`KaoyanVocabDB`) + `localStorage` 双重容灾，零后端鉴权
- **记忆算法**：改进型 SuperMemo SM-2 艾宾浩斯动态间隔调度
- **数据工程**：Python PyMuPDF 跨页水印过滤解析器 + 真题例句对齐

## 🚀 本地运行与开发

### 环境要求
- Node.js 18.0 或更高版本

### 快速启动
```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务 (支持网络局域网访问)
npm run dev

# 3. 运行全套单元测试
npm run test

# 4. 构建生产打包版本
npm run build
```

> **Windows 一键启动**：项目根目录下提供 `双击启动.bat`，双击即可全自动拉起服务并在浏览器中打开 `http://localhost:3000`。
